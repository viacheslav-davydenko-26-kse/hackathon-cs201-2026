# ДеЦе? Live

Географічна гра про Україну на основі відкритих даних. Впізнавайте область або місто Київ за статистичними підказками й обирайте відповідь на інтерактивній карті.

Проєкт університетського хакатону CS201 2026. Команда: **Big "Damn, It's" Data**.

## Грати онлайн

Застосунок розгорнуто — для гри не потрібно встановлювати Python або запускати сервер.

**[Відкрити екран ведучого й організувати гру](https://dece-hackathon.yednist.digital/static/host.html)**

1. Відкрийте посилання ведучого. На екрані з’являться код кімнати та QR для приєднання.
2. Гравці сканують QR телефоном, відкривають посилання й вводять ім’я.
3. Коли учасники приєдналися, ведучий запускає гру та керує переходами між раундами.

Гравці можуть приєднуватися через інтернет; спільна Wi-Fi-мережа з ведучим не потрібна. Для онлайн-презентації демонструйте екран ведучого й надайте учасникам посилання приєднання або QR.

## Як грати

- **Соло:** до п’яти підказок і трьох спроб. Додаткові підказки та спроби зменшують бали. Після відповіді гра показує відстань і «гаряче/холодно».
- **Кімната:** ведучий створює гру, гравці приєднуються за QR або кодом. Підказки відкриваються за таймером; кожен гравець має одну відповідь на раунд. Після раунду видно правильну область, розподіл відповідей і лідерборд.
- **Карта:** 27 регіонів, із них 25 ігрових — 24 області та місто Київ. Крим і Севастополь залишаються видимими, позначені як тимчасово окуповані й недоступні для відповідей. Київ має збільшену зону натискання.

Підказки генеруються з числових значень, рейтингів, порівнянь із середнім і категоріальних показників. Підбір перевіряє перетин множин сумісних регіонів; поточні відомі обмеження наведені нижче.

## Локальний запуск для розробки

Потрібні **Python 3.11+** і доступ до інтернету для встановлення залежностей та завантаження браузерного модуля d3-geo з CDN. Окремий Node.js-збирач не потрібен.

```bash
git clone https://github.com/viacheslav-davydenko-26-kse/hackathon-cs201-2026.git
cd hackathon-cs201-2026
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

У Windows активація середовища: `.venv\Scripts\Activate.ps1` у PowerShell.

Готові `db/game.sqlite` та `static/ua.geojson` вже є в репозиторії, тому для першого запуску перебудовувати дані не потрібно.

| Сторінка | Адреса |
|---|---|
| Соло | <http://localhost:8000/> |
| Ведучий | <http://localhost:8000/static/host.html> |
| Гравець | <http://localhost:8000/static/play.html> |
| Інтерактивна документація API | <http://localhost:8000/docs> |
| Перевірка сервера | <http://localhost:8000/health> |

### Гра з телефонів на локальному сервері

1. Відкрийте екран ведучого через доступну телефонам адресу: LAN-IP комп’ютера або публічний URL.
2. Створіть кімнату й відскануйте QR телефоном. Гравець вводить ім’я; код також можна ввести вручну.
3. Ведучий запускає раунд і керує переходами до наступних раундів.

Для пристроїв поза локальною мережею можна використати встановлений `cloudflared`:

```bash
cloudflared tunnel --url http://localhost:8000
```

Відкрийте `/static/host.html` за отриманою публічною адресою. За замовчуванням посилання приєднання будується з адреси запиту ведучого. Якщо проксі передає іншу адресу або схему, задайте правильний `PUBLIC_URL` перед запуском сервера.

`localhost` на телефоні означає сам телефон, а не комп’ютер ведучого.

### Короткий демо-режим

```bash
DEMO_ROUND_SECONDS=30 python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Це один раунд на 30 секунд, якщо `TOTAL_ROUNDS` не задано окремо. Звичайний режим — п’ять раундів по 35 секунд.

## Дані

Поточний знімок SQLite містить **30 метрик, 735 регіональних значень і 1590 фактів**. Ці числа змінюються після оновлення джерел або генератора.

| Дані | Джерело | Період у поточній версії |
|---|---|---|
| Народження, смерті, шлюби, розлучення | Держстат, SDMX-JSON через data.gov.ua | 2021 |
| Населення та середній вік | Держстат | На 01.01.2022 |
| Результати НМТ | УЦОЯО | 2025 |
| Повітряні тривоги | Vadimkin / ukrainian-air-raid-sirens-dataset | Спільне вікно 01.01–20.08.2025 |
| Межі регіонів | geoBoundaries UKR ADM1 | Знімок, зазначений у реєстрі джерел |

Точні URL, локальні файли й дати завантаження: [data/SOURCES.md](data/SOURCES.md).

Важливі правила інтерпретації:

- Каталог і значення метрик зберігають роки спостережень; під час інтерпретації їх потрібно враховувати. Зокрема, показник учасників НМТ на 1000 мешканців використовує населення на 01.01.2022, що вказано в одиницях метрики.
- Дублікати записів тривог усуваються під час обробки. Усі регіони порівнюються в одному часовому вікні; помісячні серії містять лише повні місяці цього вікна — січень–липень.
- Відсутність спостереження не прирівнюється до нуля. Наприклад, Луганська область не має метрик тривог; у Донецькій і Луганській бракує частини демографічних показників.
- Спільний період не гарантує повноти джерела: тривалі паузи без записів позначаються попередженнями в перевірці якості.

### Перебудова даних

Виконуйте з кореня репозиторію:

```bash
# З готових CSV: метрики, ранги та факти → SQLite; карта → static/
python -m etl.run_all

# З локальних сирих джерел: населення, демографія, тривоги, НМТ
python -m etl.run_all --source raw

# Звіт про покриття, джерела й підозрілі пропуски
python -m etl.check
```

Обидва варіанти `run_all` перезаписують `db/game.sqlite` і можуть оновити `static/ua.geojson`. Сирий НМТ розпаковується в `data/_extracted/`; для нього потрібне додаткове місце на диску. Завантаження зовнішніх джерел ці команди не виконують. Крок автомобільних даних поки пропускається як нереалізований.

Перезапустіть сервер після перебудови: репозиторій даних кешується в пам’яті процесу.

## Тести

```bash
# Звичайний набір; повільний тест сирого НМТ виключено через pytest.ini
python -m pytest -ra

# Усі тести, включно з повільними
python -m pytest -o addopts= -ra

# Лише повільні тести
python -m pytest -m slow -ra

# Без запису bytecode і кешу pytest
PYTHONDONTWRITEBYTECODE=1 python -B -m pytest -p no:cacheprovider -ra
```

Тести охоплюють цілісність даних, нормалізацію регіонів, ETL, генерацію фактів, бали, HTTP-контракти та ігрові сценарії. Повільний тест може створити розпакований CSV НМТ у `data/_extracted/`.

У поточному робочому дереві додані аудит-тести для ізоляції кімнат, одночасних відповідей, реальних інтеграційних сценаріїв і відповідності SQLite вихідним CSV. Два тести в `tests/test_fact_semantics.py` виявляють відомі дефекти, описані нижче. Це реальні падіння, а не пропущені тести.

Автоматизованого тестування браузера немає. Перед демонстрацією окремо перевірте QR, вибір Києва, масштабування карти, повторне відкриття сторінки й повну гру на фізичних телефонах.

## Налаштування

Змінні читаються з оточення під час запуску. Автоматичного завантаження `.env` немає.

| Змінна | За замовчуванням | Призначення |
|---|---|---|
| `PUBLIC_URL` | Адреса запиту ведучого для створення кімнати | Публічна база посилання й QR; задайте за потреби за проксі |
| `ROUND_SECONDS` | `35` | Тривалість раунду кімнати |
| `TOTAL_ROUNDS` | `5`, або `1` у демо-режимі | Кількість раундів |
| `DEMO_ROUND_SECONDS` | Не задано | Перевизначає тривалість і вмикає один раунд за замовчуванням |
| `DB_PATH` | `db/game.sqlite` | Шлях до SQLite; стандартний шлях обчислюється від кореня проєкту |
| `PARSED_DIR` | `data/parsed` | CSV-джерело та резервний репозиторій |
| `HINT_PICKER` | `facts` | Підбір за фактами; `random` — тимчасовий режим без гарантії однозначності |

Якщо SQLite відсутня, сервер читає CSV, але без згенерованих фактів стандартний picker може не сформувати раунд. У такому разі виконайте `python -m etl.run_all`.

Стан кімнат і соло-раундів живе **в пам’яті одного процесу**. Для поточної реалізації запускайте один worker; перезапуск сервера скидає ігри. SQLite зберігає статистичні дані, а не активні сесії.

## Структура

```text
app/             FastAPI, схеми, репозиторії, соло та кімнати
etl/             Обробка джерел, ранги, генерація фактів, перевірки
data/            Сирі джерела, parsed/*.csv, coverage.csv, GeoJSON
db/              Схема й готова game.sqlite
static/          Соло, ведучий, мобільний гравець, карта, CSS/JS, моки
tests/           Дані, ETL, контракти, ігрова логіка та аудит
scripts/         Експорт OpenAPI і прикладів відповідей
docs/            Контракт поведінки й збережена OpenAPI-схема
```

Стек: Python, FastAPI, SQLite, HTML/CSS, JavaScript ES-модулі та d3-geo. Мультиплеєр працює через **REST-polling**, не WebSocket.

HTTP-схеми: [app/schemas.py](app/schemas.py). Поведінка та граничні випадки: [docs/contract.md](docs/contract.md). Правила спільної роботи: [AGENTS.md](AGENTS.md). [PLAN.md](PLAN.md) містить початковий задум; актуальні можливості визначає реалізація.

Для перегляду моків додайте `?mock=1` до адреси сторінки; звичайний режим використовує справжній API. Моки — статичні приклади, а не повноцінна гра. Їхні цифри не слід використовувати як фактичну статистику.

## Поточні обмеження

- **Сумісність relative-підказок:** текст «±10% від середнього» має ширший зміст, ніж внутрішній бакет генератора. Через це множина сумісних регіонів може бути неповною, а однозначність — завищеною.
- **Послідовність категорій:** picker може повертати дві підказки однієї категорії поспіль навіть за наявності іншого допустимого порядку.
- **Картка статистики:** backend builder і frontend renderer ще не реалізовані. Прямий запит картки повертає 501; multiplayer reveal продовжується з `card = null`.
- **Автомобільні дані та LLM-загадки:** залишаються нереалізованими кроками й не входять до поточного набору можливостей.
- **Геодані:** ETL використовує готову карту з `data/parsed/`; окремий `build_geo` ще є заглушкою.
